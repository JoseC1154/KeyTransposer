    How to Use Piano Chord Transposer
    🎹 Piano Keyboard
    Tap keys to select notes. Selected keys light up in green.
    Use − / + buttons to change the number of visible octaves.
    🎵 Transposing
    Select notes, then use ▲ (up) or ▼ (down) to transpose by semitone.
    Your selected notes move together while staying in the keyboard range.
    ≈ Alternate Chords
    Select a chord and tap ≈ to see suggestions:
    • Inversions (1st, 2nd)
    • Extensions (7th, 9th, 11th)
    • Suspended chords (sus2, sus4)
    • Relative major/minor

    Tap Apply to use any suggestion. The ↶ button appears to undo (up to 5 steps).
    💾 Chord Memory
    12 scale banks (C through B), each with 12 chord slots.
    • Use bank arrows ◀ ▶ to switch between scales
    • Tap a slot to save the current chord
    • Tap again to load a saved chord
    • Open Menu → Chord Memory to manage slots
    💾 Backup & Share
    Export Data: Download all your chord banks as a JSON file
    • Backs up all 12 scale banks with saved chords
    • Save to cloud storage or share with others

    Import Data: Restore from a previous backup
    • Select a previously exported JSON file
    • Replaces current data (backup first!)
    • Perfect for syncing across devices
    ⚡ Quick Tips
    • Tap Clear to deselect all notes
    • The app auto-detects and names chords
    • Custom name chords when saving to memory
    • Works offline when installed as a PWA
    • All data saved locally on your device
